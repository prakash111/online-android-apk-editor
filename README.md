✨ Key Features

📝 Advanced APK File Editor

- Edit APK files online without extraction tools
- Popup modal editor for smooth editing experience
- Resize editor (right + bottom support)
- Instant save with auto-close option

🔥 Firebase Configuration Auto-Detection

Upload "google-services.json" and automatically detect:

- "google_api_key"
- "google_app_id"
- "google_crash_reporting_api_key"
- "gcm_defaultSenderId"
- "project_id"

⚠️ Only "firebase_database_url" needs manual input
👉 Find it in: Firebase Console → Realtime Database
